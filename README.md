# QuickFix — Local Home Services App

A local home services booking platform that connects users with nearby service providers for quick, reliable home fixes.

## 🚀 Features
- Searchable provider grid to browse available services
- Booking modal for scheduling service requests
- Session panel to track ongoing/past bookings
- (Prototype) AI-integrated smart request assistant — "QuickFix AI Triage" — for automated request handling

## 🛠️ Tech Stack
- HTML, CSS, JavaScript
- Prototype module: React + Node/Express + Anthropic API

## ⚙️ Installation
```bash
git clone https://github.com/jothishajo39-ux/quikfix.git
cd quikfix
```
Open `index.html` in your browser.
